# Конструктор КП Гуудуу

Одностраничный конструктор коммерческих предложений для ОсОО «Гуудуу Сервис». Работает в браузере без сервера и сборки: откройте `index.html`.

## Что умеет

- Шапка КП с автоматическим номером (`КП-2026-001`), датой и сроком действия.
- Секции: задача клиента, этапы работ с общим сроком, стоимость, условия оплаты, о компании, контакты, подпись и место для печати. Любую секцию можно скрыть.
- Расчёт стоимости: скидка по строке и общая скидка, НДС без начисления, включённый в цены или сверху, сумма прописью в сомах и тыйынах.
- Каталог позиций (ККМ NewCas, регистрация в ГНС, ОФД, 1С, ЭСФ, интеграции, Goodoo QR, обучение) с поиском и редактированием. Стартовые цены условные.
- Черновики: создание, дублирование, удаление, переключение.
- Копирование листа в Word, Google Docs или письмо с таблицами, а также короткой текстовой версией для мессенджеров.

## Хранение данных

Каталог и черновики хранятся в `localStorage` браузера. Они не синхронизируются между устройствами и пользователями. Очистка данных сайта в браузере удаляет их.

## Запуск

- Локально: откройте `kp-builder/index.html` двойным кликом.
- Через GitHub Pages: включите Pages для репозитория (Settings → Pages, ветка по умолчанию, папка `/root`), страница будет доступна по адресу `https://creaturedsis.github.io/working/kp-builder/`.
